# 🌉 교량 구조와 힘의 분산 - 개념 원리 탐구 실험실

추를 올리고 막대의 굵기·거리·구조를 바꾸며 힘 전달을 살펴보는 Streamlit 앱입니다.
구현은 `streamlit_app.py` 한 파일에 있습니다. 문답 제출이나 개인정보 입력은 없습니다.

## 실행 방법

Codespaces의 현재 Python 환경을 사용합니다. 가상환경 생성·활성화는 필요하지 않습니다.

```bash
python -m streamlit run streamlit_app.py
```

Codespaces의 **포트(Ports)** 탭에서 **8501**을 브라우저로 여세요.
종료는 터미널에서 `Ctrl+C`입니다. 패키지가 없는 환경에서는 필요한 항목만
`python -m pip install 패키지이름`으로 설치하세요. 필요한 의존성은 `requirements.txt`에 있습니다.
이번 물리 모형 개선에는 추가 패키지를 설치하지 않았습니다.

## 달라진 실험 기준

교량별로 미리 정해 둔 최대 추 개수와 변형 지수를 제거했습니다.
같은 SI 단위(m, N, Pa, kg)로 힘과 변위를 계산하고 처짐은 **mm**로 보여 줍니다.

- **기본 비교**: 받침 사이 거리, 종이 바닥판 폭과 골조 재료 총부피를 맞춥니다.
  막대가 많은 구조는 개별 막대가 가늘어집니다. 케이블·종이·받침은 골조 재료량과 별도이며, 골조·줄·종이 무게를 그림 아래에 표시합니다.
- **막대 굵기 같게**: 모든 구조에 같은 단면 막대를 사용합니다. 대신 골조 총재료량이 달라집니다.
- **하중**: 추 0~20개, 추 한 개 10·20·50·100 g 중 선택합니다. 기본은 0개, 한 개 20 g입니다.
  종이 바닥판이 추 무게를 길이 방향으로 고르게 전달하는 **균등하중**을 가정합니다.
  그림에 그려진 추의 개별 위치를 해석에 사용하는 것은 아닙니다.
- **자중**: 기본으로 막대·줄·종이 자체의 무게를 포함합니다. 추 0개에도 힘과 처짐이 생길 수 있습니다.
- **조건 변경**: 왼쪽에서 경간(받침 사이 거리), 재료, 막대 단면, 연결력·받침 수평력,
  줄 지름, 허용 처짐 등을 바꿀 수 있습니다. 아치 높이·트러스 칸 수/높이·주탑 높이/케이블 처짐은 각 탐구 탭에 있습니다.

**재료 성질은 특정 수수깡이나 종이를 측정한 값이 아닌 균질 재료의 예시**입니다.
교실 모형의 물리적 경향을 살펴보는 실험이며, 실제 큰 교량의 우열이나 인증된 설계 하중을 산출하는 프로그램은 아닙니다.

## 계산은 어떻게 하나요?

보·아치는 축력과 휨을 받는 2차원 Euler–Bernoulli 보 요소로, 트러스 막대·주탑·아치의 세로 지지대는
핀으로 연결한 축력 요소로 계산합니다. 줄은 인장만 허용하며 눌리는 줄은 강성에서 제외합니다.
구조 전체의 힘 평형을 풀어 변위와 부재 힘을 구합니다. 두 옆면은 하중을 절반씩 나누어 받습니다.
종이는 하중 분배와 자중에만 사용하고 보의 휨 강성은 양옆의 연속 막대가 담당합니다.

추 0~20개를 각각 계산해 다음 기준 중 먼저 도달하는 것을 확인합니다.

1. 재료의 축력·휨 강도: 축응력과 휨응력의 보수적인 선형 조합으로 검사합니다.
2. 압축 막대의 Euler 좌굴: 길고 가는 막대가 옆으로 휘어 꺾이는 한계입니다.
3. 각 축력 부재 끝의 연결 허용 힘: 양옆 연결부의 허용 힘을 합산합니다.
4. 각 받침·앵커의 수평 허용 힘: 양옆을 합한 수평 반력을 검사합니다.
5. 허용 처짐: 기본은 경간의 1/200이며, 수업용으로 변경할 수 있는 기준입니다.

**기준 대비 여유**는 이 기준들의 `허용량 ÷ 현재 요구량` 중 가장 작은 값입니다.
처짐 기준도 포함하므로 강도만의 안전율과는 구분합니다. 자중도 포함하므로 추 개수의 단순 비율과 다릅니다.
모든 요구량이 0이면 ‘힘 없음’, 기구처럼 움직이는 구조는 ‘계산 불가’입니다.

처음 기준을 넘는 개수 직전까지를 **0~20개 실험의 결과**로 표시합니다.
20개까지 기준을 만족하면 **20개 이상**으로 표시하며, 실제 최대 하중을 찾았다는 뜻은 아닙니다.
자중부터 기준을 넘으면 **0개도 기준 초과**입니다. 기준 초과는 실제 붕괴를 단정하는 표현이 아닙니다.
기준을 넘은 그림은 원래 모양으로 표시하고, 초과 처짐 숫자와 점선 곡선은 선형식의 참고 계산값으로 구분합니다.

### 계산에서 단순화한 부분

- 작은 변형의 선형 정적 평면 모형입니다. 가로 방향 흔들림은 별도 가새가 막는다고 가정합니다.
- 실제 수수깡의 속 빈 단면, 접힌 종이의 강성, 접착부 회전·박리, 전단 파괴는 포함하지 않습니다.
- 압축 부재는 양끝 힌지 Euler 하중을 사용합니다. 바닥 보의 유효 길이는 전체 경간(트러스는 한 칸),
  아치는 아치 길이의 절반입니다. 실제 유효 길이와 전체 아치의 불안정은 지지·가새 조건에 따라 달라집니다.
- 케이블의 초기 장력·형상 찾기, 대변형과 전체 좌굴, 3차원 비틀림, 바람·지진·피로는 포함하지 않습니다.
  현수교 주케이블은 수평 방향 균등하중에 가까운 **포물선**으로 시작합니다.
  케이블 자체 무게만 받는 줄의 현수선(catenary)과 구분합니다.
- 자중에는 받침·접착제 무게가 들어 있지 않습니다. 비용 점수는 물리 계산의 입력이 아닙니다.

실물 모형과 수치를 맞추려면 동일한 지지·하중 조건에서 부재 물성, 접합부 힘, 처짐을 측정해 보정해야 합니다.

## 화면 구성

처음에는 **📖 실험실 안내**가 표시됩니다. 탐구 순서, 색 범례, 용어, 계산 범위를 읽은 뒤 **🌉 교량 탐구**로 이동하세요.
하중 조절은 왼쪽, 교량 모형은 오른쪽입니다. 선생님용 계산 안내는 왼쪽 아래에 있습니다.

- **01 보와 아치**: 아치 높이와 수평 받침 힘을 바꾸며 보의 휨과 아치의 압축 전달을 비교합니다.
- **02 삼각형과 트러스**: 보강 전 사각형과 대각선이 추가된 삼각형을 나란히 표시합니다.
  대각선은 굵은 실선입니다. 이 두 그림은 같은 단면을 유지하며 오른쪽에 대각선 재료만 더합니다.
  회전이 자유로운 사각형은 불안정한 기구이므로 가상의 처짐·한계 개수를 만들지 않습니다.
  칸 수는 1~11칸이며, 칸이 많다고 한계 하중이 자동으로 커지지는 않습니다.
- **03 케이블과 주탑**: 주탑 높이와 주케이블 늘어진 깊이를 조절합니다.
  사장교의 실제 줄 각도는 거리와 높이에서 정해집니다. 장력 그래프에 해당 각도도 표시합니다.
  주탑 뒤의 고정줄·앵커를 포함합니다. 높은 주탑은 장력을 줄이더라도 좌굴에는 불리할 수 있습니다.
- **04 5대 교량 비교**: 서로 다른 두 교량을 선택하거나 전체 다섯 구조를 비교합니다.
  전체 그림은 단순교·아치교 → 트러스교 → 사장교·현수교 순서이며, 순위가 아닙니다.
  마지막 기준 이내 추를 올린 그림, 현재 하중의 처짐·여유, 하중별 곡선과 표를 제공합니다.

각 그림 아래에서 **특징·장점·단점·대표 사례 카드**를 읽을 수 있습니다.
중3 눈높이의 ‘쉽게 이해하기’ 안내를 사용하며 학생 화면에 복잡한 수식을 표시하지 않습니다.
그림의 변형 확대 배율은 표시만 바꾸며 계산 결과에 영향을 주지 않습니다.
오른쪽 위 **⋮ → Settings → Theme**에서 Light/Dark를 선택할 수 있습니다.

## 경간과 학습용 상대 건설비

전체 비교에서는 실물 교량의 경간 참고 구간과 상대 비용 점수도 보여 줍니다.
이 부분은 교실 크기 모형의 물리 계산과 별도입니다.

- 경간: FHWA 강교 형식 선택 자료의 일부 구간을 m로 환산·반올림한 예시입니다. 전체 형식의 최소·최대 길이가 아닙니다.
  현수교 약 900 m 이상은 긴 경간에서의 경제성 참고 기준입니다.
- 비용 점수: 단순교 100, 아치교 170, 트러스교 150, 사장교 240, 현수교 320은
  **앱에서 정한 학습용 점수**입니다. 보고서의 통계나 실제 비용 비율이 아닙니다.
  실제 공사비는 경간·폭·지반·시공 방법·지역에 따라 달라집니다.

## 코드를 수정하려면

- `MATERIALS`: 기본 예시 물성. 실측값으로 보정할 수 있습니다.
- `build_model()`: 교량 모양, 단면, 지지 조건과 자중.
- `assemble()` / `stable_solve()` / `recover()`: 힘 평형과 처짐·강도·좌굴 등의 검사.
- `solve_sweep()`: 추 0~20개를 검사해 실험 범위의 결과를 찾습니다. 반복 계산은 캐시합니다.
- `BRIDGE_GUIDES`: 이론 학습 카드의 문구.
- `BRIDGE_PLANNING`: 경간 참고 구간과 별도의 학습용 비용 점수.
