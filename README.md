# 교량 구조 디지털 탐구 학습지

중학교 3학년 기술·가정 수업에서 사용하는 교량 구조 학습 자료이자 실험·실습을 대체하는 Streamlit 앱입니다.
다섯 교량의 구조와 하중 전달 원리를 학습하고, 화면에서 추를 조절해 하중 실험을 할 수 있습니다.
교량의 정밀 설계나 실제 성능 순위를 판단하는 프로그램이 아닙니다.

## 실행

```bash
python -m streamlit run streamlit_app.py
```

필요한 패키지는 `requirements.txt`에 있습니다. Codespaces에서는 포트 8501을 브라우저로 엽니다.
학습 화면·계산·그래프는 `streamlit_app.py`에 있으며 외부 데이터나 로그인은 필요하지 않습니다.

## 학습 흐름

상단에는 **실험실 안내 / 교량 탐구 / 교량 비교** 세 탭이 있습니다.

1. **교량 구조 알아보기**: 모양과 주요 부재, 하중을 견디는 원리, 하중 전달 과정, 활용 상황을 짧게 읽습니다.
2. **하중 실험하기**: 그림 바로 아래에서 추를 늘리며 처짐과 힘의 방향을 관찰합니다.
3. **교량 비교하기**: 같은 하중에서의 처짐, 구조와 하중 전달 방식, 모형의 한계를 비교합니다.

학습 목표는 구조적 특징 설명, 하중 전달 이해, 하중에 따른 반응 관찰, 결과 차이의 이유 설명입니다.
수업의 구조 학습과 종이·수수깡 모형의 지우개 하중 실험을 디지털 학습 자료와 화면 속 하중 실험으로 대체합니다.
실물과 디지털 모형은 재료와 연결 조건이 달라 결과가 일치할 필요는 없습니다.
업로드된 두 원본 PPT의 내용을 확인하여 학습 흐름과 대조했습니다.

- [다양한 교량의 구조](다양한%20교량의%20구조.pptx): 20장. 기둥·보, 다섯 교량의 구조와 활용 사례를 설명합니다.
- [교량 만들기 실습](교량%20만들기%20실습.pptx): 14장. 종이·수수깡 모형 제작, 지우개 하중 실험, 결과 비교와 모둠 토의로 이어집니다.

앱은 구조 학습·하중 실험·결과 비교에 집중하며, 실물 제작 모형과 계산 모형의 차이를 구분합니다.

| 교량 | 대표적인 하중 전달 과정 |
| --- | --- |
| 단순교(거더교) | 상판 → 보 → 양쪽 받침 → 지반 |
| 아치교 | 상판 → 세로 지지대 → 아치 → 양쪽 받침·지반 |
| 트러스교 | 상판 → 삼각형 막대 → 받침 → 지반 |
| 사장교 | 상판 → 사장 케이블 → 주탑·기초 / 뒤쪽 케이블 → 앵커 |
| 현수교 | 상판 → 행어 → 주케이블 → 주탑·앵커리지 → 지반 |

모형의 상판 보도 하중을 나누어 받습니다. 표는 각 구조의 대표 경로입니다.

## 화면 디자인

기본 테마는 밝은 배경과 차분한 청록색 조작 요소를 사용합니다. 설정은 `.streamlit/config.toml`에 있습니다.
인장의 파랑과 압축의 빨강은 그대로 유지하며, 색과 화살표 방향·범례를 함께 표시합니다.
본문·보조 설명·결과 수치의 크기와 간격을 구분하고, 불필요한 카드와 그림자는 추가하지 않습니다.
핵심 용어는 굵게 표시하고, 인장·압축에는 글자와 배경색을 함께 적용합니다. 처짐과 관찰할 부분에는 밑줄을 사용합니다.
학습 단계에는 소수의 아이콘을 사용하며, 첫 화면의 개념 그림과 교량별 하중 전달 도식으로 긴 설명을 보완합니다.
개념 그림은 계산된 시뮬레이션 그림과 구분합니다. 하중 변경 메시지는 추 개수와 처짐의 전후 값을 중심으로 짧게 표시합니다.
구조 원리와 하중 전달 과정, 처짐 수치와 관찰 설명은 데스크톱에서 나란히, 모바일에서 세로로 배치합니다.
교량 그림의 주석과 범례를 키우고, 단순교·아치교·트러스교는 기본 보기에서 화면을 더 넓게 사용합니다.
비교 표의 행 간격과 그래프의 축·단위·범례를 정리했습니다. 넓은 비교 표는 표 안에서 가로로 이동할 수 있습니다.

## 기본 조작과 표시

- 본문의 교량 선택과 추 개수 조절이 기본 조작입니다. 추 1개의 기본 질량은 20 g입니다.
- 추 개수와 총질량의 관계를 `개수 × 한 개의 질량 = 총질량(g)`으로 표시합니다.
- 추는 경간 중앙의 같은 위치에 한 개씩 쌓습니다. 주황 화살표 하나가 그 위치의 전체 추가 하중을 나타냅니다.
- 빨강 **→ ←**는 압축, 파랑 **← →**는 인장입니다. 화살표 길이는 힘의 크기가 아닙니다.
- 단순교의 보는 긴 사각형 띠로 그려, 휨이 있을 때 윗부분 압축과 아랫부분 인장을 구분합니다.
- 케이블교의 케이블·행어는 상판 윗면에 연결합니다. 주탑 하부와 기초는 하중 전달을 위한 개념 표시입니다.
- 오른쪽 **＋ / － / ↺** 버튼은 화면 크기를 50~250%로 조절합니다. 계산에는 영향을 주지 않습니다.
- 실제 계산된 처짐은 mm로 표시합니다. 그림의 변형 확대 배율과 보의 표시 두께는 실제 치수와 구분합니다.
- 설정한 기준에 접근하는 정도는 계산된 기준 사용량에 근거합니다. 실제 붕괴까지의 진행률이 아닙니다.

## 심화 설정과 한계 관찰

사이드바와 심화 설정은 기본으로 접혀 있습니다. 기존 설정은 다음 범주에서 모두 접근할 수 있습니다.

- 비교 조건: 경간, 재료 비교 기준, 재료 예시, 추 한 개의 질량
- 재료·단면·연결부와 기준: 막대·종이·케이블 특성, 연결부·받침 허용 힘, 허용 처짐, 자체 무게
- 교량 형상: 아치 높이, 트러스 칸 수·높이·보강, 주탑 높이, 주케이블의 늘어진 깊이
- 표시와 한계 참고: 변형 확대 배율, **한계 초과 참고 계산 보기**

기본 모드에서는 선택한 교량의 계산된 허용 개수까지만 올립니다. 조건 변경으로 한계가 낮아지면 개수도 줄어듭니다.
심화 설정에서 참고 모드를 켜면 안정적으로 계산되는 모형에 한해 0~20개의 참고값을 확인할 수 있습니다.
기준 초과 시 그림의 변형·부재력은 마지막 기준 이내 상태를 유지하고, 추와 주황 하중 화살표는 현재 개수를 표시합니다.
처음부터 기준 초과라면 처음 계산된 참고 형상을 유지합니다. 평형이 확보되지 않으면 수치를 만들지 않습니다.
이 표시는 실제 붕괴 이후의 모습이나 파손 과정을 예측하지 않습니다.

최대 추 개수, 하중(N), 기준 대비 여유, 부재·모형 정보는 접힌 **심화 결과**에 있습니다.
트러스 보강·칸 수, 케이블교 주탑 높이의 기존 비교는 접힌 **심화 탐구**에 유지합니다.
보강 전 트러스에는 사각형이 옆으로 기울어지는 예시를 회색 점선으로 겹쳐 표시합니다. 막대 길이와 받침 위치는 유지하며, 계산된 변형량이나 붕괴 형상이 아닙니다.
심화 그래프는 영역을 펼칠 때 생성하여 기본 추 조절 중에는 불필요한 그림 생성을 줄입니다.

## 교량 비교

기본 비교는 구조·원리·현재 처짐·모형 한계를 모은 표와 하중–처짐 그래프 하나로 구성합니다.
기본 그래프는 기준 이내 범위만 표시하며, 초과 참고 모드를 켜면 점선 참고값을 함께 표시합니다.
두 교량만 선택하는 비교도 유지합니다. 각 교량의 한계 상태 그림과 재료량 정보는 심화 비교에 있습니다.
건설비 점수, 참고 경간 그래프, 여유·처짐 막대그래프, 반복되는 학습 카드는 제거했습니다.
별도의 교량 설계자 체험은 없습니다.

토의 질문과 답변 입력란은 제공하지 않습니다.
‘20개 이상’은 실험 범위에서 한계에 닿지 않았다는 뜻이므로, 해당 결과끼리는 순위를 정할 수 없습니다.

경간·추 질량·골조 재료 조건을 공통으로 사용합니다. 기본은 골조 막대의 총부피를 맞추므로 막대가 많으면 가늘어집니다.
케이블·종이·받침은 같은 재료량으로 맞추지 않으며, 막대 굵기 기준을 고르면 골조 총량도 달라집니다.
자체 무게와 각 구조의 단순화 가정도 결과에 영향을 줍니다. 비교의 트러스교는 대각선 보강 구조입니다.
모형 결과는 실제 교량의 절대적인 성능 순위가 아닙니다.

## 계산 모형

기존 강성·부재력·허용 기준 계산을 사용하고, 추 하중의 적용 조건을 중앙 집중 하중으로 변경했습니다.
SI 단위(m, N, Pa, kg)를 사용하며, 처짐만 mm로 환산합니다.
보·아치는 축력과 휨을 받는 2차원 보 요소, 나머지 막대는 축력 요소, 케이블은 인장만 받는 요소입니다.
추의 전체 하중은 상판의 경간 중앙에 수직으로 적용합니다. 다섯 교량의 비교에도 같은 위치를 사용합니다.
홀수 칸 트러스는 중앙 보에 계산용 절점을 추가합니다. 보의 연속성·총재료량·기존 좌굴 길이와 받침 조건은 유지합니다.
자체 무게에는 막대·케이블·종이를 포함하며, 기존처럼 분포 하중으로 반영합니다. 종이는 질량에만 반영하고 보의 휨 강성에 더하지 않습니다.
고르게 분배했던 이전 하중 조건과 달라 처짐·부재력·최대 허용 추 개수도 달라집니다. 현재 조건으로 매번 다시 계산합니다.

0~20개를 계산하여 재료 강도, 압축 막대의 좌굴, 연결부 힘, 받침·앵커 수평 힘, 허용 처짐 중 먼저 도달하는 기준을 찾습니다.
20개까지 만족하면 ‘20개 이상’, 자체 무게부터 초과하면 ‘0개도 기준 초과’로 표시합니다.
선형 작은 변형 모형이며 케이블 초기 장력·대변형·시공·바람·지진·피로는 포함하지 않습니다.
재료 성질은 특정 수수깡이나 종이를 측정한 값이 아닙니다. 실물과 수치를 맞추려면 별도 측정과 보정이 필요합니다.

## 검증

```bash
python -m unittest discover -s tests -v
```

다섯 교량, 추 증감과 계산 갱신, 범위 유지·자동 보정, 한계 초과 참고 모드, 확대, 케이블·기초 연결,
재료·형상 변경, 비교 일관성, 토의 질문·답변 입력란 제거, 학습 자료와 실험·실습 대체 목적 안내를 확인합니다.
중앙 하중의 위치·힘의 평형, 단순교의 이론 처짐·휨 모멘트, 홀수 칸 트러스의 중앙 하중, 추의 적층 표시도 검증합니다.
검증용 브라우저 도구는 프로젝트 실행 의존성에 추가하지 않습니다.
Chromium의 데스크톱(1366px)·모바일(390px) 화면에서 다섯 교량, 추 조절, 오른쪽 확대 버튼과 페이지 가로 넘침을 확인했습니다.
320px·390px 화면에서 글자 크기와 그림 영역을 추가 확인했으며, 기본 밝은 테마에서 보조 설명의 명도 대비는 약 6.3:1입니다.
