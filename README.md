# 🌉 교량 구조와 힘의 분산 - 개념 원리 탐구 실험실

추를 올리며 **하중 전달 경로, 인장·압축·휨을 받는 부재, 처짐의 변화**를 살펴보는 Streamlit 앱입니다.
다섯 교량의 원리를 실제 건설 상황과 연결하고 하중 실험과 교량 비교를 제공합니다.
구현은 `streamlit_app.py` 한 파일에 있습니다. 개인정보 입력은 없습니다.

## 실행 방법

Codespaces의 현재 Python 환경을 사용합니다. 가상환경 생성·활성화는 필요하지 않습니다.

```bash
python -m streamlit run streamlit_app.py
```

Codespaces의 **포트(Ports)** 탭에서 **8501**을 브라우저로 여세요.
종료는 터미널에서 `Ctrl+C`입니다. 패키지가 없는 환경에서는 필요한 항목만
`python -m pip install 패키지이름`으로 설치하세요. 필요한 의존성은 `requirements.txt`에 있습니다.
이번 물리 모형 개선에는 추가 패키지를 설치하지 않았습니다.

## 달라진 실험 기준

교량별로 미리 정해 둔 최대 추 개수와 변형 지수를 제거했습니다.
같은 SI 단위(m, N, Pa, kg)로 힘과 변위를 계산하고 처짐은 **mm**로 보여 줍니다.

- **기본 비교**: 받침 사이 거리, 종이 바닥판 폭과 골조 재료 총부피를 맞춥니다.
  막대가 많은 구조는 개별 막대가 가늘어집니다. 케이블·종이·받침은 골조 재료량과 별도이며, 모형 무게와 단면 정보는 결과의 심화 영역에서 확인합니다.
- **막대 굵기 같게**: 모든 구조에 같은 단면 막대를 사용합니다. 대신 골조 총재료량이 달라집니다.
- **하중**: 본문에서 추를 **선택한 교량의 계산된 허용 개수까지만** 올릴 수 있습니다(실험 범위 최대 20개).
  교량·재료·형상·추 무게 변경으로 한계가 낮아지면 개수가 자동으로 줄어듭니다. 추가 가능한 추가 없으면 조작을 비활성화합니다.
  추 한 개의 기본 무게는 20 g이며, 심화 설정에서 10·50·100 g으로 바꿀 수 있습니다.
  종이 바닥판이 추 무게를 길이 방향으로 고르게 전달하는 **균등하중**을 가정합니다.
  그림에 그려진 추의 개별 위치를 해석에 사용하는 것은 아닙니다.
- **자중**: 기본으로 막대·줄·종이 자체의 무게를 포함합니다. 추 0개에도 힘과 처짐이 생길 수 있습니다.
- **조건 변경**: 교량 선택은 본문에 있습니다. 경간(받침 사이 거리), 재료, 막대 단면, 연결력·받침 수평력,
  줄 지름, 허용 처짐과 교량 형상은 왼쪽의 접힌 **심화 설정**에서 바꿀 수 있습니다.

**재료 성질은 특정 수수깡이나 종이를 측정한 값이 아닌 균질 재료의 예시**입니다.
교실 모형의 물리적 경향을 살펴보는 실험이며, 실제 큰 교량의 우열이나 인증된 설계 하중을 산출하는 프로그램은 아닙니다.

## 계산은 어떻게 하나요?

보·아치는 축력과 휨을 받는 2차원 Euler–Bernoulli 보 요소로, 트러스 막대·주탑·아치의 세로 지지대는
핀으로 연결한 축력 요소로 계산합니다. 줄은 인장만 허용하며 눌리는 줄은 강성에서 제외합니다.
구조 전체의 힘 평형을 풀어 변위와 부재 힘을 구합니다. 두 옆면은 하중을 절반씩 나누어 받습니다.
종이는 하중 분배와 자중에만 사용하고 보의 휨 강성은 양옆의 연속 막대가 담당합니다.

추 0~20개를 각각 계산해 다음 기준 중 먼저 도달하는 것을 확인합니다.

1. 재료의 축력·휨 강도: 축응력과 휨응력의 보수적인 선형 조합으로 검사합니다.
2. 압축 막대의 Euler 좌굴: 길고 가는 막대가 옆으로 휘어 꺾이는 한계입니다.
3. 각 축력 부재 끝의 연결 허용 힘: 양옆 연결부의 허용 힘을 합산합니다.
4. 각 받침·앵커의 수평 허용 힘: 양옆을 합한 수평 반력을 검사합니다.
5. 허용 처짐: 기본은 경간의 1/200이며, 수업용으로 변경할 수 있는 기준입니다.

**기준 대비 여유**는 이 기준들의 `허용량 ÷ 현재 요구량` 중 가장 작은 값입니다.
처짐 기준도 포함하므로 강도만의 안전율과는 구분합니다. 자중도 포함하므로 추 개수의 단순 비율과 다릅니다.
모든 요구량이 0이면 ‘힘 없음’, 기구처럼 움직이는 구조는 ‘계산 불가’입니다.

처음 기준을 넘는 개수 직전까지를 **0~20개 실험의 결과**로 표시합니다.
20개까지 기준을 만족하면 **20개 이상**으로 표시하며, 실제 최대 하중을 찾았다는 뜻은 아닙니다.
자중부터 기준을 넘으면 **0개도 기준 초과**입니다. 기준 초과는 실제 붕괴를 단정하는 표현이 아닙니다.
기준을 넘으면 마지막 기준 이내 상태의 **변형·부재력·받침 반력**을 유지합니다. 추와 주황 하중 화살표는 현재 개수에 맞게 표시합니다.
그림에 유지된 상태의 추 개수를 명시하며, 초과 처짐 숫자와 점선 곡선은 현재 하중에 대한 선형 참고값입니다.
자중부터 기준 초과이면 처음 계산된 참고 형상을 유지합니다. 평형을 계산할 수 없는 구조만 변형 없이 뼈대로 표시합니다.

### 계산에서 단순화한 부분

- 작은 변형의 선형 정적 평면 모형입니다. 가로 방향 흔들림은 별도 가새가 막는다고 가정합니다.
- 실제 수수깡의 속 빈 단면, 접힌 종이의 강성, 접착부 회전·박리, 전단 파괴는 포함하지 않습니다.
- 압축 부재는 양끝 힌지 Euler 하중을 사용합니다. 바닥 보의 유효 길이는 전체 경간(트러스는 한 칸),
  아치는 아치 길이의 절반입니다. 실제 유효 길이와 전체 아치의 불안정은 지지·가새 조건에 따라 달라집니다.
- 케이블의 초기 장력·형상 찾기, 대변형과 전체 좌굴, 3차원 비틀림, 바람·지진·피로는 포함하지 않습니다.
  현수교 주케이블은 수평 방향 균등하중에 가까운 **포물선**으로 시작합니다.
  케이블 자체 무게만 받는 줄의 현수선(catenary)과 구분합니다.
- 자중에는 받침·접착제 무게가 들어 있지 않습니다. 비용 점수는 물리 계산의 입력이 아닙니다.

실물 모형과 수치를 맞추려면 동일한 지지·하중 조건에서 부재 물성, 접합부 힘, 처짐을 측정해 보정해야 합니다.
기본 설정에서는 트러스가 높은 하중 결과를 보일 수 있습니다. 삼각형 부재의 힘 분담과 트러스 바닥 보의 짧은 좌굴 길이가 영향을 줍니다.
다만 골조 재료량 비교에서 케이블은 제외되고 지지·좌굴·연결 조건도 단순화되어 있어, 이 결과를 실제 교량의 우열로 해석하지 않습니다.
계산식은 균등하중 단순보의 처짐 이론식과 대조해 확인했습니다.

## 화면 구성

처음에는 **📖 실험실 안내**가 표시됩니다. 탐구 순서, 색 범례, 용어, 계산 범위를 읽은 뒤 **🌉 교량 탐구**로 이동하세요.
상단 탭은 **실험실 안내 / 교량 탐구 / 교량 비교**의 세 가지입니다.
탐구 화면에서는 본문 위쪽에서 상황과 교량을 고른 뒤 다음 순서로 학습합니다.

**건설 상황 → 교량 그림 → 추 개수 조절 → 구조적 반응 관찰 → 하중 전달 원리 → 실제 적용 조건**

추 조절기는 교량 그림 바로 아래에 하나만 표시합니다. `추 개수 × 한 개의 질량 = 총질량(g)`과
추가 하중(N)을 함께 표시하며, 비교 화면도 같은 추 개수를 사용합니다.
교량 그림 오른쪽의 작은 **＋ / － / ↺** 버튼으로 화면을 50~250% 범위에서 조절합니다.
버튼은 그림 옆에 세로로 배치하며, 각 버튼에 마우스를 올리면 기능 안내가 표시됩니다.
그림 영역을 더 크게 제공하며, 확대한 그림은 드래그해 옮길 수 있습니다.
화면 확대는 계산값이나 심화 설정의 **변형 확대 배율**에 영향을 주지 않습니다.
실험 그림에는 **부재 이름과 힘의 방향 화살표**가 기본으로 표시됩니다.
빨강 **→ ←**는 안으로 누르는 압축, 파랑 **← →**는 밖으로 당기는 인장입니다.
부재 방향과 계산된 축력 부호에 따라 화살표를 배치하며, 화살표 길이는 힘의 크기를 뜻하지 않습니다.
단순교의 휨은 보 윗면의 압축 화살표와 아랫면의 인장 화살표로 나타냅니다. 부재 이름과 휨 안내는 유지합니다.
상판 아래 보는 처짐을 따라 휘어지는 긴 사각형 띠로 표현합니다. 단순교에 휨이 있으면
윗부분은 빨강, 아랫부분은 파랑으로 채워 내부의 압축·인장 화살표가 잘 보이게 합니다.
띠의 두께는 학습을 위한 표시용 두께이며 실제 계산 단면이나 응력 크기 분포를 뜻하지 않습니다.
추는 띠의 윗면에, 받침은 아랫면에 맞추어 표시합니다.
사장교·현수교는 케이블과 구분되도록 상판 띠를 얇게 표시하고, 케이블·행어를 상판 윗면에 연결합니다.
주탑은 상판 아래로 이어지는 하부와 그 아래 기초를 함께 표시해 하중 전달 경로를 보여 줍니다.
하부 주탑은 개념 표시이며, 이 그림 보완으로 계산 부재·절점·형상·강성은 바꾸지 않습니다.
자중·추가 모두 없으면 힘 화살표를 표시하지 않습니다. 기준 초과 시 화살표도 유지된 상태의 부재력을 나타냅니다.
경간·재료·단면·연결부·받침·허용 처짐·형상·변형 확대 등은 왼쪽의 접힌 **심화 설정**에서 바꿉니다.
사이드바도 기본으로 접혀 있으며, 교사용 계산 안내를 유지합니다.
기준 대비 여유, 최대 추 개수, 하중의 한계 결과와 모형 정보는 **심화 결과**에 표시합니다.

- **01 짧은 하천**: 경제적인 짧은 경간 상황에서 단순교를 살펴보고, 보의 휨과 처짐을 관찰합니다.
- **02 견고한 계곡**: 양쪽 지반과 교대가 튼튼한 상황에서 아치교의 압축력과 수평 반력을 살펴봅니다.
- **03 열차가 지나는 길**: 무거운 열차와 높은 강성이 필요한 상황에서 트러스 부재의 인장·압축을 살펴봅니다.
  접힌 **심화 탐구**에서 보강 전 사각형과 대각선이 추가된 삼각형을 나란히 표시합니다.
  대각선 보강 설정은 기본 탐구 그림에도 반영되며, 5종 비교에서는 보강된 트러스를 사용합니다.
  대각선은 굵은 실선입니다. 이 두 그림은 같은 단면을 유지하며 오른쪽에 대각선 재료만 더합니다.
  회전이 자유로운 사각형은 불안정한 기구이므로 가상의 처짐·한계 개수를 만들지 않습니다.
  칸 수는 1~11칸이며, 칸이 많다고 한계 하중이 자동으로 커지지는 않습니다.
- **04 넓은 강**: 중간 교각 설치가 어려운 상황에서 사장교의 케이블 장력과 주탑 높이를 살펴봅니다.
  사장교의 실제 줄 각도는 거리와 높이로 정해집니다. 주탑 뒤 고정줄·앵커도 모형에 포함합니다.
- **05 깊은 해협**: 초장경간 상황에서 현수교의 행어·주케이블 하중 전달을 살펴봅니다.
  모형은 실제 초장경간 성능이나 바람에 의한 진동을 검증하지 않습니다.
- **06 비교·정리**: 상단의 독립된 **🔎 교량 비교** 탭에서 서로 다른 두 교량을 선택하거나 전체 다섯 구조를 비교합니다. 추 개수는 교량 탐구 탭의 값을 함께 사용합니다.
  전체 그림은 단순교·아치교 → 트러스교 → 사장교·현수교 순서이며, 순위가 아닙니다.
  마지막 기준 이내 추를 올린 그림, 현재 하중의 처짐·여유, 하중별 곡선과 표를 제공합니다.
- 각 교량에서 상황을 먼저 읽고 추 실험을 한 뒤, 하중 전달 원리와 그 상황에서 유리할 수 있는 이유 및 한계를 연결합니다.
  트러스 보강·칸 수 비교와 케이블교 주탑 높이 비교는 접힌 **심화 탐구**에 유지합니다.

추 개수나 무게를 바꾸면 현재 조건의 계산된 처짐과 힘을 짧은 설명으로 함께 확인할 수 있습니다.
추 개수만 바꾼 경우에는 직전 개수와 현재 개수의 실제 계산값으로 처짐 변화를 설명합니다.
교량·경간·재료·형상 등 계산 조건이 바뀌면 이전 비교를 초기화해 서로 다른 모형을 비교하지 않습니다.
교량을 바꿔도 공통 심화 설정은 유지되며, 추 개수는 새 교량의 허용 범위 안에서 유지됩니다. 자중과 추가 모두 없으면 힘이 거의 없다고 안내하며,
불안정한 구조의 처짐이나 붕괴 후 변형을 만들어 내지 않습니다.
모형에는 추의 하중을 균등하게 나누어 적용하며, 실제 교통 하중을 그대로 재현하지는 않습니다.
중3 눈높이의 ‘쉽게 이해하기’ 안내를 사용하며 학생 화면에 복잡한 수식을 표시하지 않습니다.
그림의 변형 확대 배율은 표시만 바꾸며 계산 결과에 영향을 주지 않습니다.
오른쪽 위 **⋮ → Settings → Theme**에서 Light/Dark를 선택할 수 있습니다.

## 경간과 학습용 상대 건설비

전체 비교에서는 실물 교량의 경간 참고 구간과 상대 비용 점수도 보여 줍니다.
이 부분은 교실 크기 모형의 물리 계산과 별도입니다.

- 경간: FHWA 강교 형식 선택 자료의 일부 구간을 m로 환산·반올림한 예시입니다. 전체 형식의 최소·최대 길이가 아닙니다.
  현수교 약 900 m 이상은 긴 경간에서의 경제성 참고 기준입니다.
- 비용 점수: 단순교 100, 아치교 170, 트러스교 150, 사장교 240, 현수교 320은
  **앱에서 정한 학습용 점수**입니다. 보고서의 통계나 실제 비용 비율이 아닙니다.
  실제 공사비는 경간·폭·지반·시공 방법·지역에 따라 달라집니다.

## 코드를 수정하려면

- `MATERIALS`: 기본 예시 물성. 실측값으로 보정할 수 있습니다.
- `build_model()`: 교량 모양, 단면, 지지 조건과 자중.
- `assemble()` / `stable_solve()` / `recover()`: 힘 평형과 처짐·강도·좌굴 등의 검사.
- `solve_sweep()`: 추 0~20개를 검사해 실험 범위의 결과를 찾습니다. 반복 계산은 캐시합니다.
- `BRIDGE_GUIDES`: 이론 학습 카드의 문구.
- `BRIDGE_PLANNING`: 경간 참고 구간과 별도의 학습용 비용 점수.

```bash
python -m unittest discover -s tests -v
```

다섯 교량 표시, 본문 추 조절기 중복 여부, 추 증가·감소 시 계산값과 설명의 일치,
추 무게·경간·교량 변경 시 비교 초기화와 값 유지, 형상 변경과 보강 해제에 따른 불안정 안내,
자중 없는 0개 상태, 최대 추 결과 및 두 교량·전체 비교를 확인합니다.

추를 추가할 수 없는 상태와 사장교·현수교의 상판 윗면 연결도 검증합니다.
